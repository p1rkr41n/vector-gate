### Use Cases

VRL can be used to describe the transformations used in the `reduce` transform. A new prototype transform should be made to see how viable this is and potentially deprecate the existing transform.

There are several issues with the existing `reduce` transform this might fix too, such as https://github.com/vectordotdev/vector/issues/18219 or https://github.com/vectordotdev/vector/issues/18239
