## Description

## Problem

According to [the documentation](https://vector.dev/docs/reference/vrl/expressions/#string-characteristics), a string literal of `s'\\'` should produce a single backslash, given that you have to escape backslash as a special character.  The result of this should be `"\\"`.  Something seems off in the lexer where the escaped backslash is being literally interpreted, and the output becomes `"\\\\"`.

## Example

`.nope = s'\\'` --> `"\\\\"`

## Version
Tested on the latest version as of this writing, `version = "0.19.0"`
