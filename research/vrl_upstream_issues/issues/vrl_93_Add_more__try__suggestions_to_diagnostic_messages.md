## Description

Now that VRL has settled in, go through our existing diagnostic messages, and see if we can add any `try` suggestions to the diagnostic message.

This would propose potential fixes, allowing operators to apply a fix without having to go through the language documentation.

Eventually, this can be used to automate any of those fixes.
